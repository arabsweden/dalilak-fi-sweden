# دليلك في السويد · Dalilak fi Sweden 🇸🇪

**A practical Arabic guide to life in Sweden**

دليل عربي عملي شامل للحياة في السويد: الهجرة، الدوائر الحكومية، السكن، العمل، والسياحة في ستوكهولم.

</div>

---

## ✨ What it covers

- 🏛️ Swedish authorities and how to deal with them
- 🏠 Housing
- 💼 Work and job search
- ✈️ Immigration basics
- 🗺️ Tourism in Stockholm
- 🤖 AI assistant powered by Google Gemini (server-side, the key never reaches the browser)

## 🛠️ Tech stack

TypeScript · React · Vite · Tailwind CSS · Express · Google Gemini API

## 🚀 Run locally

```bash
npm install
cp .env.example .env.local   # add your own GEMINI_API_KEY
npm run dev
```

> 🔐 Never commit real API keys. `.env` files are ignored by git.
